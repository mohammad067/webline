# Security Policy

## Supported Versions

Currently, only the latest version of this project is supported. Please ensure you are using the most recent release.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you believe you have found a security vulnerability, please do NOT report it via a public issue.

Instead, please report vulnerabilities by contacting us through the following methods:

1. **GitHub Profile:** Contact the project maintainer via their GitHub profile: [mohammad067](https://github.com/mohammad067).
2. **GitHub Private Reporting:** If available, use the GitHub private vulnerability reporting feature for this repository.

### What to include in your report

To help us address the issue as quickly as possible, please include:

- A description of the vulnerability.
- Steps to reproduce the issue.
- Potential impact if the vulnerability is exploited.
- Any suggested fixes or mitigations.

## Process

After receiving a report, we will:

1. Acknowledge receipt of the report.
2. Investigate the issue to confirm the vulnerability.
3. Work on a fix.
4. Notify you once the vulnerability has been addressed.

Thank you for helping us keep this project secure!
